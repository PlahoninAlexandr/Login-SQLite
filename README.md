# Telegram Crypto Position Bot (RU)

Бот Telegram на Python для расчёта размера позиции, стоп-лосса, тейк-профита и базовой аналитики (через бесплатный Hugging Face или эвристику). Поддерживает LONG/SHORT и корректировку размера позиции с повторной аналитикой.

## Возможности
- Ввод депозита, риска на сделку (в % или суммой), направления (LONG/SHORT), цены входа
- Стоп-лосс: процент от цены входа или фиксированная цена
- Тейк-профит: R-множитель или фиксированная цена
- Расчёт размера позиции, R:R, номинала, предупреждений
- Регулировка размера позиции (+10% / −10% / ручной ввод)
- Краткая аналитика от ИИ (через HF API, с эвристическим бэкапом)

## Установка
1. Python 3.10+
2. Установите зависимости:
```bash
pip install -r requirements.txt
```

## Переменные окружения
- `TELEGRAM_BOT_TOKEN` — токен бота
- `HF_TOKEN` — (опционально) токен Hugging Face для вызова Inference API
- `HF_MODEL` — (опционально) модель для Inference API (по умолчанию TinyLlama/TinyLlama-1.1B-Chat-v1.0)
- `QUANTITY_STEP` — (опционально) минимальный шаг количества (по умолчанию 0.0001)

## Запуск
```bash
export TELEGRAM_BOT_TOKEN=123:ABC
# опционально:
export HF_TOKEN=hf_xxx
python -m telegram_crypto_bot.main
```

Проверка конфигурации:
```bash
python -m telegram_crypto_bot.main --check
```

## Команды в Telegram
- `/start` — приветствие и старт
- `/calc` — начать расчёт
- `/cancel` — отмена диалога

## Важно
- Бот не даёт инвестиционных рекомендаций. Используйте на свой риск.
